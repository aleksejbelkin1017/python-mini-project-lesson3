# Описание проекта
Этот проект направлен на создание набора инструментов для эффективной обработки и защиты данных. 

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/username/project-x.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```

# Цели проекта
1. Маскирование номеров счетов и карт.
2. Фильтрация данных по состоянию.
3. Сортировка данных по дате.

# Описание модулей и функций
## Модуль masks.py
Модуль masks.py содержит функции get_mask_card_number и get_mask_account. 
Эти функции предоставляют мощные инструменты для автоматизации обработки данных, 
повышения их безопасности и удобства использования, что делает их полезными в различных 
приложениях, где требуется защита и управление конфиденциальной информацией. 
#### get_mask_card_number
* Входные данные: Номер карты в виде строки или целого числа.
* Выходные данные: Маска номера карты, где первые 6 цифр и последние 4 цифры отображаются 
явно, а остальные символы заменены на “*”. Номер разделён на блоки по 4 цифры.
* Пример использования:
```
card_number = "1234567890123456"
masked_card = get_mask_card_number(card_number)
print(masked_card)  # Выведет: 1234 5678 9012 3456
```
#### get_mask_account
* Входные данные: Номер счёта в виде строки или целого числа.
* Выходные данные: Маска номера счёта в формате “**” и 4 последние цифры номера.
* Пример использования:
```
account_number = "1234567890"
masked_account = get_mask_account(account_number)
print(masked_account)  # Выведет: **90
```

##  Модуль widget.py
Модуль widget.py содержит функции mask_account_card и get_date.
Эти функции предоставляют удобные инструменты для обработки данных, 
такие как маскирование номеров счетов и карт, а также преобразование дат 
в удобный для чтения формат. 
#### mask_account_card
* Входные данные: Строка, содержащая тип и номер счета или карты.
* Выходные данные: Маска номера счета или карты, где текстовые символы остаются неизменными, 
а числовые заменяются маской.
* Пример использования:
```
masked_number = mask_account_card("Visa 1234567890123456")
print(masked_number) # Выведет: Visa 1234 5678 9012 3456
```
#### get_date
* Входные данные: Строка с датой в формате “YYYY-mm-ddTHH:MM:SS.fff”.
* Выходные данные: Дата в формате “ДД.ММ.ГГГГ”.
* Пример использования:
```
formatted_date = get_date("2023-01-04T14:37:39.000")
print(formatted_date) # Выведет: 04.01.2023
```

## Модуль processing.py
Модуль processing.py содержит функции filter_by_state и sort_by_date.
Эти функции предоставляют удобные инструменты для обработки данных, 
такие как фильтрация словарей по состоянию и сортировка списка словарей по дате. 
#### filter_by_state
* Входные данные:
* * dict_with_state: список словарей.
* * state (опционально): значение, которое должен иметь ключ state в словарях для их отбора. 
По умолчанию ‘EXECUTED’.
* Выходные данные: Новый список словарей, в котором остаются только те элементы, 
у которых ключ state равен указанному значению.
* Пример использования:
```
dict_list = [
    {"state": "PROCESSING", "data": "data1"},
    {"state": "EXECUTED", "data": "data2"},
    {"state": "CANCELED", "data": "data3"}
]
filtered_list = filter_by_state(dict_list, "EXECUTED")
print(filtered_list) # Выведет: [{"state": "EXECUTED", "data": "data2"}]
```
#### sort_by_date
* Входные данные:
* * list_dict: список словарей.
* * arg_for_sort (опционально): флаг для сортировки по возрастанию (True) или убыванию (False). По умолчанию True.
* Выходные данные: Новый список словарей, отсортированный по дате в ключе date.
* Пример использования:
```
dict_list = [
    {"state": "PROCESSING", "date": "2023-01-01"},
    {"state": "EXECUTED", "date": "2023-01-02"},
    {"state": "CANCELED", "date": "2023-01-03"}
]
sorted_list = sort_by_date(dict_list)
print(sorted_list) # Выведет: [{"state": "CANCELED", "date": "2023-01-03"}, {"state": "EXECUTED", "date": "2023-01-02"}, {"state": "PROCESSING", "date": "2023-01-01"}]
```
